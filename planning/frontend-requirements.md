## 3. 详细规格

### 3.1 导航栏改造 (App.tsx)

**现状**: 三标签 → 总览 | 目标链 | 计划
**改为**: 四标签 → 总览 | 目标链 | 计划 | 档案

```
NavBar: [总览] [目标链] [计划] [档案]
```

- 样式与已有标签一致 (浅紫选中态)
- `档案` Tab 放在最后

---

### 3.2 档案页 — 四层表单 (新页面)

**数据来源**: `GET /api/life-archive` → `PATCH /api/life-archive/layer-*`

#### 页面布局

```
┌────────────────────────────────────────────┐
│  人生档案                         保存按钮  │
├────────────────────────────────────────────┤
│  [子标签栏: 核心特质 | 资源能力 | 未来蓝图] │
├────────────────────────────────────────────┤
│                                            │
│  当前子标签对应的表单内容                    │
│                                            │
└────────────────────────────────────────────┘
```

#### 子标签 1：核心特质 (layerCore)

| 字段 | 类型 | 录入方式 | 必填 |
|------|------|---------|------|
| MBTI | string (4字母) | 4 个下拉框拼合 (E/I, N/S, T/F, J/P) 或 直接选完整类型 | 否 |
| 大五人格·开放性 | 1-100 数字 | slider 或 数字输入框 | 否 |
| 大五人格·尽责性 | 1-100 数字 | slider 或 数字输入框 | 否 |
| 大五人格·外向性 | 1-100 数字 | slider 或 数字输入框 | 否 |
| 大五人格·宜人性 | 1-100 数字 | slider 或 数字输入框 | 否 |
| 大五人格·神经质 | 1-100 数字 | slider 或 数字输入框 | 否 |
| 盖洛普优势 | string[] (最多5项) | 标签式输入 (输入文本 → 按回车添加为标签) | 否 |

**原型参考**: `planning/life-archive-prototype.html` 的「核心」子标签

#### 子标签 2：资源能力 (layerResources)

| 字段 | 类型 | 录入方式 |
|------|------|---------|
| 核心技能·名称 | string | 文本框 |
| 核心技能·等级 | string | 文本框 |
| 核心技能·年限 | number | 数字输入 |
| 核心技能·描述 | string | 多行文本框 |
| 时间·工作日可用 | number | 数字输入 |
| 时间·周末可用 | number | 数字输入 |
| 时间·固定支出描述 | string | 多行文本框 |
| 财务状况·安全垫 | string | 文本框 |
| 财务状况·收入结构 | string | 文本框 |
| 财务状况·可投资金 | string | 文本框 |
| 财务状况·财务阶段 | string | 文本框 |
| 支持系统·导师资源 | string | 多行文本框 |
| 支持系统·协作搭档 | string | 多行文本框 |
| 支持系统·情感支持 | string | 多行文本框 |

**原型参考**: `planning/life-archive-prototype.html` 的「资源」子标签

> 注意: 能量精力和健康基础由 AI 复盘后写回 (用户确认)，不在 Web 提供编辑入口。

#### 子标签 3：未来蓝图 (layerFuture)

| 字段 | 类型 | 录入方式 | 必填 |
|------|------|---------|------|
| 10年愿景 | string | 多行文本框 | 是 |
| 3年愿景 | string | 多行文本框 | 是 |
| 1年目标 | string | 多行文本框 | 是 |
| 动力来源 | string | 多行文本框 | 是 |
| 为什么是现在 | string | 多行文本框 | 是 |
| 最低可接受结果 | string | 文本框 | 是 |
| 理想结果 | string | 文本框 | 是 |
| 结果描述 | string | 多行文本框 | 否 |
| 正面榜样 | string | 多行文本框 | 是 |
| 反面警示 | string | 多行文本框 | 是 |

**原型参考**: `planning/life-archive-prototype.html` 的「蓝图」子标签

### 3.4 AI 目标建议 UI

#### 触发入口

- **总览页**: 在月进度下方增加「AI 建议年度目标」按钮
- **目标链页**: 在目标树上方增加「AI 建议」按钮
- **计划页**: 在 PeriodSelector 旁增加「AI 建议计划」按钮

#### AI 建议弹窗/区域

```
┌──────────────────────────────────────┐
│  AI 目标建议           [关闭]        │
│                                       │
│  基于你的 10 年愿景「成为 AI leader」 │
│  和当前能力评估，AI 建议如下：        │
│                                       │
│  ┌─ 建议 1 ─────────────────────────┐│
│  │  📊 年度目标: 年收入达到 50 万    ││
│  │     类型: 数值 | 目标: 500000     ││
│  │  [接受] [修改] [拒绝]             ││
│  └──────────────────────────────────┘│
│                                       │
│  ┌─ 建议 2 ─────────────────────────┐│
│  │  📊 年度目标: 完成 3 个开源项目   ││
│  │     ...                           ││
│  └──────────────────────────────────┘│
│                                       │
│  [全部接受]                           │
└──────────────────────────────────────┘
```

**API**: 
- `POST /api/goals/ai-suggest/yearly` → 获取建议列表
- `POST /api/goals/ai-suggest/yearly/confirm` → 确认写入
- 月度同理: `POST /api/plans/ai-suggest/monthly`

## 4. 待确认的交互问题

以下是从 6-14 的工作中遗留的 7 个问题，本次需要确认：

| # | 问题 | 选项 | 建议 |
|---|------|------|------|
| 1 | MBTI 录入方式 | A) 四个下拉拼合 (E/I, N/S, T/F, J/P) / B) 直接输入完整类型 | **建议 B** — 少扰民 |
| 2 | 大五人格录入 | A) slider 滑条 / B) 数字输入 | **建议 A** — 更直观 |
| 3 | 盖洛普优势录入 | A) 标签式追加 (输入后回车) / B) 文本输入 | **建议 A** |
| 4 | 能力技能录入 | A) 卡片追加 / B) 弹窗表单 | **建议 A** — 在页面内展开 |
| 5 | 子标签保存策略 | A) 每个子标签独立保存按钮 / B) 整体保存 | **建议 A** — 防丢失 |
| 6 | AI 建议写入策略 | A) 直接写入 ACTIVE / B) 写入 PENDING 等用户确认 | **建议 B** |
| 7 | 摘要推送方式 | A) 页面加载时拉取 / B) WebSocket 推送 / C) 手动刷新 | **建议 A** |
